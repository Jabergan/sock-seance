# Sock Séance — Hackyard Yard #4

A browser-based sock color matching app. Hold a sock up to your camera, lock the color, hold up another — the spirits decide if they match.

## Demo

▶️ https://youtube.com/shorts/fInoUD9zJBg

## Try It Live

🔗 https://sock-seance.vercel.app

## How It Works

- Rear camera samples color inside the reticle circle
- Weighted Euclidean color distance (2r² + 4g² + 3b²) determines if two socks match
- Adjustable tolerance slider for lighting conditions
- Match: the spirits reunite and fly off
- No match: they shake and drop back

## Stack

Single HTML file. Vanilla JS. WebGL ghost sprites. No frameworks. No backend. No accounts.

Built in one evening.
